# ManagedCoder Agency Operations privacy

Updated 2026-10-02. Applies to this Skills-only package.

The package contains instructions, templates and artwork. It has no ManagedCoder server, analytics SDK, MCP server or collection endpoint. Installing it does not send agency data to ManagedCoder. Data you provide is processed by the host application under that application's terms and privacy controls.

If you authorize an existing connector, that service and the host handle its data according to their own policies. This package does not grant connector permissions. Do not paste passwords, API keys or unnecessary personal or HR data.

Support is through the repository's public issue tracker. Do not post confidential client or personal information in public issues. A future connected product requires its own data-flow disclosure and privacy review.
