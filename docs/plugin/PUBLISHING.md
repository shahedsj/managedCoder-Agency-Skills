# Publishing checklist and status

Official starting point: https://developers.openai.com/plugins/quickstart
Submission: https://developers.openai.com/plugins/deploy/submission
Packaging: https://developers.openai.com/plugins/build/plugins
Guidelines: https://developers.openai.com/plugins/plugin-guidelines

1. Build and check the archive. Review privacy, usage terms and public metadata.
2. Test in supported ChatGPT/Codex surfaces. Record actual results; structural tests do not establish model behavior.
3. Sign in to https://platform.openai.com/plugins with the authorized developer account. Confirm publisher identity and eligibility.
4. Create a Skills-only submission, upload the ZIP, inspect automated checks and fix returned errors. Include evaluation cases if supported.
5. Complete any requested human review material. Submit, track review and publish only after approval.
6. Update this file with real submission ID, review status and directory URL. Never invent them.

Current status: local release candidate prepared. No public-directory approval or publication has occurred. The available portal session showed a sign-in screen. Account eligibility, portal validation and human review remain external gates.

Skills-only distribution does not justify digital-goods upsells or ads in operating instructions. Connected capabilities should be a separately reviewed product: the current rules do not allow adding MCP to an existing Skills-only listing. Do not rebuild the existing ManagedCoder platform for the starter release.

Updates: regenerate the ZIP and submit package/metadata changes through the portal. Do not assume GitHub commits automatically update an approved Skills-only listing.
