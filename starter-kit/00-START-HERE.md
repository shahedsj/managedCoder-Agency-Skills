# The Agency Skill File Starter Kit

**From ManagedCoder — AI training for agency owners, by SJ Innovation**

---

## What this is

YC's president, Garry Tan, gave a talk called "Own Your Intelligence." The idea is simple: write down how you do a task once, in plain English, and an AI agent can run it for you forever. He calls this a "skill file." A page of instructions any smart person could follow — and so can Claude or ChatGPT.

This kit gives you 5 skill files, already written for the tasks every agency owner does every week. You didn't have to write them. Just use them.

## How to use these (2 ways, pick one)

### Option A — Claude Project (best if you have Claude with Projects)
1. Create a new Claude Project called "Agency Ops."
2. Open Project settings → Custom Instructions.
3. Copy in the skill file(s) you want active. You can stack more than one.
4. Now just paste your raw material into the chat — notes, a transcript, a company name — and Claude follows the instructions automatically.

### Option B — Paste per use (works with Claude, ChatGPT, or any AI chat)
1. Open a new chat.
2. Paste the whole skill file at the top.
3. Paste your raw material underneath it.
4. Send. That's it.

Either way works. Option A is less typing if you do this every week — that's the whole point of a skill file. Write it once, never explain it again.

---

## The one rule that makes this actually work

If the AI gets something wrong the first time, don't just fix the output — fix the skill file. Add the missing rule, the exception, the format you actually wanted. Next time it will get it right, because now it knows. That's the difference between a tool you fight with every week and a tool that gets better every week.
