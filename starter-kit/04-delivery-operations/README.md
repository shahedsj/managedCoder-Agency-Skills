# Delivery, Scope & Operations

Skills for turning commitments into owned work and making delivery risk visible before it becomes a client escalation or margin problem.

## Current skills

- `03 Meeting Notes to Tasks` - convert explicit commitments into approved, non-duplicate tracked work
- `20 Scope Creep Watchdog` - compare new requests against the approved scope baseline
- `21 Project Risk Review` - recompute project R/Y/G from current delivery evidence and define recovery

This category will continue expanding around handoffs, delivery visibility, acceptance, and repeatable project operations.
