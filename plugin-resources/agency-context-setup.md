# Agency Context Setup

Help the owner reach a useful result quickly. Ask for services, their role and the immediate operating problem. Offer a client status report as an easy first task. Accept UNKNOWN for missing facts.

Use [the context template](assets/agency-context-pack.md) to produce a portable Markdown pack. Gather more details only when needed: timezone, working calendar, current priorities, team roles, preferred systems, approved policies and writing samples. Do not require signup or an external app.

Separate confirmed agency policy, proposed assumptions and starter thresholds. Use the owner's voice rather than a fixed person's style. Exclude credentials, sensitive HR notes and unnecessary client details. Record sources and dates for changing facts.

Return the pack, material gaps and a suggested next operating Skill. The available workflows are weekly owner decisions, client status, scope changes, project risk, meeting processing and delegated task review.

The pack is not persistent memory. The user can supply it in later conversations or request storage through a suitable authorized tool. Do not save automatically or claim it will be available forever.
